# Recovery OS — strony publiczne

Ten katalog jest publikowany przez GitHub Pages (repozytorium `recovery-os`, gałąź `main`, katalog główny).

- `index.html` — strona główna
- `app/` — wersja przeglądarkowa aplikacji (wersja offline: biblioteki wbudowane, bez CDN)
- `polityka-prywatnosci.html`, `usun-konto.html` — wymagane przez Google Play

Źródło: prywatne repozytorium aplikacji (`strona-publiczna/` + `wydania/Recovery-OS-X.Y.Z-offline.html`).
W kodzie aplikacji jest tylko publiczny adres projektu Supabase i klucz publiczny (publishable) — dostęp do danych chronią reguły RLS w bazie.
